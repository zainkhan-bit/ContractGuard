# Security review for 1.0

**Scope:** the threat model of the architecture blueprint (§16.2, T1–T16) against the code at the 1.0 release
candidate. **Method:** for each threat, the mitigation was located in the code and the test that proves it was run;
missing mitigations were fixed and tested during the review. **Reviewer:** internal (maintainer, assisted by an AI
code reviewer). An external review was not available for 1.0; the [security policy](https://github.com/zainkhan-bit/ContractGuard/blob/main/SECURITY.md)
invites reports.

## Findings fixed during this review

| #   | Finding                                                                                                                                                                                                                                                                                                                                                                                    | Severity     | Fix                                                                                                                                                                                                                                                                           |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R1  | **T11 not implemented.** Findings copied contract values (`previous`/`current`) without truncation or redaction, so a changed default of a `password` or `apiKey` property appeared in reports and PR comments.                                                                                                                                                                            | Medium       | Values are truncated (200 characters, 50 items, depth 8); defaults and enum values of properties, parameters and headers named like secrets are replaced by `[redacted]`. | R2  | **T12 partly implemented.** Console output printed spec-derived text (property names, paths, values) verbatim, so an OpenAPI document could send terminal escape sequences (screen clearing, OSC 52 clipboard writes). Test: `packages/cli/test/security.test.ts`.                                                                 |
| R3  | **T2 for comparisons.** Comparison and projection recursed per `$ref` hop; a 2,000-schema reference chain overflowed the stack (exit code 4).                                                                                                                                                                                                                                              | Medium (DoS) | Comparison defers pairs deeper than 256 to a worklist; projection walks iteratively. Same input now finishes in about 10 s. Test: `packages/engine/test/unit/diff.test.ts`.                                                                       |
| R5  | **T9 had no lint rule.** Spec patterns were not executed anywhere, but nothing prevented it.                                                                                                                                                                                                                                                                                               | Low          | ESLint forbids `new RegExp(…)`/`RegExp(…)` in `packages/*/src`.                                                                                                                                                                                                               |
| R6  | **T14/T15 CI gates missing.** No license allowlist check and no OpenSSF Scorecard.                                                                                                                                                                                                                                                                                                         | Low          | `scripts/check-licenses.mjs` runs in `pnpm lint` (14 production dependencies, all MIT or ISC); `.github/workflows/scorecard.yml` added.                                                                                                                                       |

## Residual risks

- **No external review** before 1.0. Planned when the project has a second maintainer or sponsor.
- **YAML parsing cost** grows with document size (see the [performance report](./performance-1.0.md)); limits
  bound it, but a 20 MB YAML document still takes tens of seconds.
- **Secret detection by name** cannot catch secrets under neutral names (`default: sk_live_…` in a property called
  `value`). Specifications should not contain secrets.
